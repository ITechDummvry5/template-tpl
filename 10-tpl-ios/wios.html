Getting Started

Quick Start

Add WIOS to any project by importing two CSS files and one JS file. No build step, no npm, no dependencies.

ℹ
Files needed
Download core.css, docsUi.css (optional, for docs pages only), and wios.js. That's it.
1
Link the stylesheet
Add core.css in your <head>.
HTML 
<link rel="stylesheet" href="core.css">
2
Add the JavaScript
Include wios.js before your closing </body>. It auto-initialises.
HTML 
<script src="wios.js"></script>
3
Start building
Use WIOS classes directly in your HTML. All components are class-based — no JavaScript configuration required for most usage.
HTML 
<button class="wios-btn wios-btn-primary wios-btn-lg">
  Hello WIOS!
</button>

Getting Started

Theming

WIOS ships with light and dark themes out of the box. The active theme is set via data-wios-theme on <html>.

💡
Auto theme detection
wios.js automatically reads prefers-color-scheme on first load and persists your choice in localStorage.

Toggle via JS

Data attribute toggle

JS
// Toggle with one call
WIOS.toggleTheme();

// Set explicitly
WIOS.applyTheme('dark');
⚠
Button trigger shorthand
Add data-wios-toggle-theme to any element to auto-wire a theme toggle click handler — no JS needed.

Components

Toasts

Fire toasts from JS with WIOS.toast(). They appear in the bottom-right and auto-dismiss after 3.5s.

JS
WIOS.toast({
  message:  'Changes saved!',
  subtitle: 'Your profile has been updated.',
  type:     'success',  // primary | success | warning | danger
  duration: 3500,         // ms
});
